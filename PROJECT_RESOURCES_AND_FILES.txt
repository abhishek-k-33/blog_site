4. CLIENT-SIDE BROWSER TECHNOLOGIES & APIS USED
================================================================================
• localStorage:
  - "theme": Persists "dark-mode" or "light-mode" across page reloads with zero flicker.
  - "miniblogs_bookmarks": Stores saved story objects ([{id, title, author}]) for offline library access.

• sessionStorage:
  - "miniblogsSplashShown": Tracks splash screen playback so the intro animation only runs once per browser session.

• Web APIs & DOM APIs:
  - Selection & Range API: Calculates exact bounding rect coordinates to anchor floating bubble toolbars over selected text.
  - FileReader API: Converts user-selected image files to Base64 data URLs for inline article embeds.
  - ContentEditable & document.execCommand: Provides rich text formatting (bold, italic, headings, lists, quotes, links).
  - requestAnimationFrame: Throttles dynamic scroll progress calculations for lag-free 60fps navbar morphing.
